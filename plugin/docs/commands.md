# Command reference

| Command | Description |
|---|---|
| `apply` | Execute approved on-page proposals against WordPress (refuses anything not approved) |
| `citations` | Track AI answer-engine citations and share of voice for the profile's query set |
| `competitors` | Run competitor content intelligence and surface gaps against the profile |
| `daily` | Run the daily organic signal pull (append-only, never mutates) |
| `export` | Export the brain to CSV for Sheets, Looker Studio, or any BI tool |
| `image` | Create the featured image / social card for a drafted post |
| `import-audit` | Import an external claude-seo audit report as gated proposals |
| `keywords` | Run tiered keyword intelligence - ideas, competitor gaps, or CSV import |
| `measure` | Measure applied or published on-page changes at day 7 and day 28 |
| `monday-report` | Write a stakeholder-shareable weekly summary of what moved, shipped, and needs a decision |
| `monthly-audit` | Run the monthly deep organic audit across all eight specialists |
| `onsite-audit` | Audit on-page SEO for a URL or a whole site section (read-only) |
| `produce` | Draft a publish-ready post from an approved content brief (six-stage pipeline) |
| `propose` | Turn audit findings or signals into concrete gated on-page change proposals |
| `publish` | Publish an approved, drafted content item to WordPress (refuses unapproved items) |
| `reset` | Guided teardown of an organic-os site - what gets deregistered automatically, what you must delete or revoke yourself, and why |
| `setup` | Onboard a site into organic-os (interview + brain scaffold + routines) |
| `sites` | Manage organic-os sites - add another website, switch the active site, or show registry status |
| `start` | The guided front door - run this first |
| `status` | Show organic-os site status - pending approvals, recent signals, next routine |
| `task-board` | Show the organic-os work queue and mirror it to Notion when available |
| `weekly` | Run the weekly organic health check + reflection |
